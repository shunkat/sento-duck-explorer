## 初回有効化時の検証

1. 公開先・所有者・公開状態を照合し、手元のコードとの関係を確認。
2. 秘密情報検査・ライセンス確認・ビルドを通した内容だけを同期。
3. Kiroの接続権限を対象リポジトリだけに限定し、ユーザーが確認した権限で接続。
4. 上記プロンプトと期限付きスケジュールを登録し、一覧のEnabled・対象・次回日時を確認。
5. 最初の実行結果を読み、PRの内容と秘密情報検査を確認。登録前に「定期実行中」と報告しない。
