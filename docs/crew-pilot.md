2. 実装ワーカー1名：専用worktreeで不具合修正と必要なテスト・結果文書を作る。コードの書き込み担当はこの1名だけ。

ワーカーは最大2名で、追加の孫ワーカーを作らない。設定による上限保証とは扱わず、ConductorのBoardで実際の起動数を確認する。通常チャットのConductorを使い、新規Bot・Heartbeat・追加の毎時ジョブは初回試行に含めない。

## 初回実行で確認した環境

- ユーザーの明示承認により、この親チャットと配下2ワーカーだけを「信頼」にした。全チャットに適用するYOLOは選ばず、拒否ルール・sandboxは変更していない。
- 依存導入と開発サーバーの管理は実装ワーカーだけが行う。検証役は同じworktreeで同時に `npm ci` を実行しない。ブラウザー操作は実装役から検証役へ順に渡す。
- 専用Viteは `http://127.0.0.1:5181/`。既存IDE用サーバーとは分け、他の開発プロセスを停止しない。Crewのシェルでは必要に応じてNodeの実行パスを補う。
- Crewの正規UIでローカル許可リストに `127.0.0.1:5181` だけを追加した。表示名はプレビュー用だが、[公式Browser文書](https://kiro.dev/docs/crew/features/browser/)ではAgent browserにも適用される設定である。
- 組み込みのKiro Chromiumを導入し、専用プロファイルで接続済みと確認した。個人Chromeは接続していない。HTTP 200やブラウザー接続済み表示だけでは、ゲーム描画・操作の成功とは扱わない。
- 14:07 JST、対象 `d9d7f1f` で実装役が描画成功を報告し、CodexもCrewライブ表示で3D浴室・3キャラクター・目的表示を確認した。独立検証役は同コミットの既存83テスト成功を報告した。操作経路・違反・再開の検証とは別の初期確認である。
