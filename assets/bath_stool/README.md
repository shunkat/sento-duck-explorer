# Ivory bath stool

The original reference → Meshy 6 Lite → Blender correction → GLB pipeline has produced a revised v02 for the five existing washing-station slots. The selected local asset preserves the actual generated source and replaces the earlier broad smoothing workflow with measured, feature-supported retopology. Final in-game visual acceptance remains pending.

Selected v02: **0.36 × 0.30 × 0.36 m**, bottom-center origin, +Y up / +Z front; **4,610 triangles**, one ivory material, no textures, **84,676 bytes**. Four legs, the central drain and underside clearance remain intact. Source-derived quad sections, supported subdivision, local arch correction, protected feature loops and detailed-surface normal transfer improve the seat, drain and arch/foot contours. The untouched raw mesh is retained in the editable scene and was verified against a fresh import.

The model remains an approximation from a single reference. Close-ups can reveal polygonal contours, and unseen underside geometry is not a recovered manufacturing design. Local asset QA does not replace the user's deferred game-view checks.
