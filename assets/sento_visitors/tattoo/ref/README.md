# Koi and waves tattoo artwork

`koi_waves__v01.png` is original Japanese irezumi-inspired artwork generated on
2026-11-22 with the built-in OpenAI image-generation tool through Codex. The
exact model version was not exposed. The image uses a large koi, curling waves
and a red peony, with indigo outlines, ivory and muted teal. It was created for
the requested tattooed adult customer, from a text prompt without third-party
image inputs. It is not a copy of a named artist's tattoo or a real person's
tattoo, and contains no lettering or affiliation symbol.

The original 1086 × 1448 RGBA PNG is preserved without pixel or metadata edits.
Its alpha and original `caBX` provenance chunk are retained. The exact prompt,
byte count and checksum are in [provenance.json](provenance.json). A scoped
original-binary check found no personal filesystem paths, private candidate
paths or file URIs; this is not an exhaustive metadata privacy guarantee.

MIT to the extent permitted by law. This does not assert guaranteed copyright
protection or exclusively human authorship. The underlying visitor geometry is
separately derived from Quaternius CC0 sources; see [the parent attribution](../../ATTRIBUTION.md).

Material authoring projects this artwork onto the visitor's back and selected
upper-body areas in Blender and packs it into a runtime atlas. It does not
alter the source artwork. The model's face, hands and lower body remain clear.
See [the visitor production record](../README.md) for accepted model checksums,
inspections and the distinction between generated art and adapted geometry.
